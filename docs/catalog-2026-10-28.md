## 套餐与额度

| 产品 | 当前档位 | 本次适配 |
|---|---|---|
| Kimi | Go / Plus / Pro / Max / Ultra | Plus 起有 Kimi Code；Pro 起有高速版及 1M 上下文。新套餐显示 5 小时和月总额度；旧套餐保留周窗口 |
| MiniMax M Plan | Go / Explore / Build | 三档均含 M3.1 Flash，Explore / Build 另含 H3 视频；沿用现有额度接口 |
| MiniMax Token Plan | Plus / Max / Ultra | 保留原套餐与查询 |
| OpenCode | Go / Go Plus | 补入新模型；月费为 $10 / $40，各模型额度不同 |
| 腾讯 Token Plan | 通用 / Hy，均有 Lite / Standard / Pro / Max | 补充 Hy 名称与 provider 别名，使用现有套餐归属统计 |

Kimi 解析器同时接受当前嵌套响应、camelCase / snake_case 用量字段和旧版计数。旧计数存在时优先使用计数，避免把同一响应中的零比例当成真实剩余额度；没有周字段的新套餐不会生成周窗口。`TIME_UNIT_MINUTE: 300` 正确归为 5 小时。

新增的 Kimi Coding Plan、MiniMax M Plan provider 按订阅分类，查询开关不改变计费分类；用户指定的 API 分类仍优先。现有 `kimi-code` 沿用订阅插件识别规则，通用 `kimi` / `minimax` provider 保留原有配置。

目录迁移只添加新 ID、更新未被修改的旧默认价。手动价格、主动取消挂载和既有账本金额保留。价格目录用于费用匹配，推理模型配置仍由 DSH 管理。
