# 设置页与插件页

当前迁移阶段，以下两个入口显示同一个完整设置组件：

- 左下角设置 → 费用。
- 插件 → 费用计量（dsh-cost-meter）→ 插件详情页中的配置区域。

两个入口共用现有配置、实时快照、自动保存和按需加载，不产生第二份账本或轮询。插件页通过 DSH 原生 `plugins.bundle.config` 插槽注册，包名为 `dsh-cost-meter`。旧宿主没有该插槽时，设置入口继续可用；插件管理器稍后加载时会自动接入。

## 待启用的纯展示页

`src/settings-overview/index.js` 提供只读看板，展示今日、本月和累计费用、预算、已启用的余额及额度来源、Token 用量和今日会话。数据来自现有快照与 Codex 额度订阅，保留查询错误和查询时间；未查询不当作零额度。费用沿用既有币种及是否计入 Plan 的配置，额度百分比标明“剩余”。

该页面没有配置输入、凭据编辑、历史导入、清除或价格同步操作。设置调整仍在插件页完成。

目前 `src/client/03-settings-panels-main.js` 中的 `SETTINGS_DISPLAY_ONLY` 为 `false`，纯展示页不会取代现有设置页，也不会在正常导航中加载。

后续 DSH 启用新的设置布局时，将该常量改为 `true` 后运行 `npm run build`。届时只有左下角设置 → 费用改为只读看板；插件页继续保留完整设置。改回 `false` 并重新构建即可恢复双入口配置，不迁移或修改用户数据。

## 验证

`node test/settings-pages.mjs` 检查当前源码、构建产物和未来启用模式的原生插槽、共享状态、语言切换及卸载清理。

`node test/settings-pages-browser.mjs` 启动使用合成数据的本地 React 预览，提供两个当前入口及待启用展示页的交互检查，不读取真实账户或账本。
