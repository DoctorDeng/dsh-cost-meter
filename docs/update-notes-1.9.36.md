# v1.9.36：余额名称选项与输入区额度位置

余额卡默认显示“余额”。在“费用 → 显示 → 侧栏”中选择“官方余额”，开启“显示余额来源（DeepSeek）”，名称会显示为“DeepSeek 余额”。关闭后恢复简短名称；悬停提示始终说明余额来自 DeepSeek 官方账户。

在“费用 → 额度”展开任意 Coding Plan 或 OpenCode Go，“显示位置”现在包含“输入框上方”，对应输入框上方的横向额度条。还可以选择侧栏与输入框上方、设置页与输入框上方，或全部位置。显示预览中的同名选项同步生效。

每家厂商单独选择位置，移动一家不会改变其他厂商。位置选择不会启用原先关闭的订阅查询，也不会修改凭据。只选择输入框上方时，额度仍会自动更新，保留刷新操作。

已有的输入区横条设置保持原来的效果。手动选择单家位置后，单家选择优先于横条默认设置；例如为 Z.ai 选择“主页面侧边栏”，即使默认横条开启，Z.ai 也只显示在侧栏。预算和 Codex 的独立开关保持原有规则。

配置经过补丁校验、磁盘清洗和两端 codec，保存后重新打开仍能恢复选择。验证包括真实 DSH 宿主中的仅输入框显示与刷新、各位置组合的浏览器切换、中英文选项，以及余额来源开关和侧栏预览。
