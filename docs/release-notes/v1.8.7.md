## v1.8.7

- Fixes [#201](https://github.com/Han-1413141/dsh-cost-meter/issues/201): in DSH Desktop, a signed-in official account now provides the balance without any Open Platform API key. When no dedicated key is configured, the plugin reads the same wallet as **Settings → Account** (topped-up plus bonus) through the host `deepseekAccount` service instead of failing with HTTP 401. Source order is dedicated key, then signed-in account, then model credentials; an account-side query failure is reported as a failure and does not fall back to another credential or become a zero balance.

## 中文

- 修复 [#201](https://github.com/Han-1413141/dsh-cost-meter/issues/201)：DSH 桌面版登录官方账号后，无需开放平台 API Key 即可读取余额。未配置余额专用 Key 时，插件经宿主 `deepseekAccount` 服务读取与「设置 → 账号」同源的钱包（充值 + 赠送），不再固定报 HTTP 401。来源顺序为 余额专用 Key → 已登录官方账号 → 模型凭据；账号侧查询失败会如实提示，不会改用其它凭据重试，也不会退化为零余额。
