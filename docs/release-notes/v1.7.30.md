## v1.7.30 更新

- **OpenRouter 透传定价**：OpenRouter 模型不再记 `$0`。内置 4 模型静态快照（2026-09-17：`meta/muse-spark-1.3-contributor`、`google/gemini-3.8-flash`、`qwen/qwen3.8-flash`、`z-ai/glm-5.3-flash`，USD/百万 token），旧账本按 `pricing-openrouter-v1` 自动回填重算。
- 启动、官方价格同步与每小时从 `openrouter.ai/api/v1/models` 刷新全量价目；加法合并保留未覆盖旧 id，`prompt: "-1"` 聚合路由与非法行自动跳过，失败保留本地快照并不翻转官方同步状态。
- `test/verify.mjs` 新增快照/回填/解析单测；完整验证通过。

完整用法见[定价说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.30/docs/openrouter-pricing.md)。

## Upgrade / 升级

```sh
dsh plugin --profile web add dsh-cost-meter@1.7.30
```

或使用固定版本安装脚本：

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.30/install.ps1 | iex
```

完全退出并重启 DSH，再刷新 Web UI。旧账本的 `openrouter:*` $0 桶在启动回填后自动按新快照计价。

**English:** OpenRouter models no longer cost $0 — a built-in 4-model snapshot (2026-09-17) backfills old ledgers via `pricing-openrouter-v1`. Startup, price sync and hourly refresh pull the full catalog from `openrouter.ai/api/v1/models` with additive merge; aggregate (`prompt: "-1"`) and invalid rows are skipped, and failures keep the local snapshot without flipping the official sync status. Includes snapshot/backfill/parser regressions and full verification.
