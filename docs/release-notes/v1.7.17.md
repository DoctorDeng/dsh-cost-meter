# v1.7.17：SCNet 外部控制台额度快照

SCNet 可读取账本目录的 `scnet_official.json`，优先展示外部控制台快照中的已用 Credits 和总额度，覆盖本地账本看不到的其他工具用量。保留小数和采集时间，中英文明确标注来源。

整合并补齐 PR #114：严格区分采集时间与重置时间；缺失、无效、超过 16 KiB、采集超过 24 小时或已跨周期时回退本地估算。有界异步读取不会把损坏文件扩散为整个费用面板失败，也不会改写账本。

外部采集器需另行提供，插件不自动登录/采集控制台。文件格式、更新和账号切换说明见 [接入文档](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.17/docs/scnet-official-snapshot.md)。

## 升级

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.17/install.ps1 | iex
```

升级后重启 dsh web，并刷新浏览器页面。
