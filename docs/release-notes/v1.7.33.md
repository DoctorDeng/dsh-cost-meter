## v1.7.33 — Xiaomi MiMo Token Plan quotas / 小米 MiMo Token Plan 额度

### English

Adds native **Xiaomi MiMo Token Plan** support to the Coding Plan quotas (Settings → Cost → Quotas), the 11th vendor. The card shows the plan credits and compensation credits windows (used %), the period-end reset (Beijing time) and a balance row, with the same enable switch, display position and refresh interval as every other vendor; sidebar cards, the quota strip and the Token Plan usage stats all include it.

**Credential = the MiMo console cookie, not an API key.** Log in at `platform.xiaomimimo.com`, press F12 → Network → find the `balanceAlertConfig` request and paste the full `cookie` request header into the MiMo card (it must include `serviceToken` and `userId`; stored in the DSH credential store as `MIMO_COOKIE`). Console cookies last about 24 hours — copy a fresh one when the card reports an expired login. The Token Plan inference keys (`tp-*` / `ttp-*`) have no usage endpoint and cannot query quotas; this is a platform limitation, shared by CodexBar / cc-switch integrations.

Queries hit `platform.xiaomimimo.com/api/v1` (`tokenPlan/usage`, `tokenPlan/detail`, `balance`): usage is the primary window source, the period-end reset and balance row are best-effort extras that never block it. Missing credentials, malformed cookies and expired logins each get their own bilingual hint. Plan/API dual-track classification now maps `xiaomi-token-plan-*` style provider IDs to the MiMo plan side.

### 中文

Coding Plan 额度(设置 → 费用 → 额度)新增第 11 家「小米 MiMo Token Plan」:套餐积分 / 补偿积分窗口(已用%)、周期截止(北京时间)重置与余额行,启用开关、显示位置、刷新间隔与其余厂商一致;侧边栏卡片、额度横条与 Token Plan 用量统计一并接入。

**凭据是小米开放平台控制台 Cookie,不是 API Key。**登录 `platform.xiaomimimo.com` 后按 F12 →「网络」→ 找到 `balanceAlertConfig` 请求,把请求头 `cookie` 整段粘贴进 MiMo 卡片(需含 `serviceToken` 与 `userId`,DSH 凭据库以 `MIMO_COOKIE` 托管)。控制台 Cookie 约 24 小时过期,卡片提示登录态过期时重新复制即可。Token Plan 推理专用 Key(`tp-*` / `ttp-*`)无用量端点、不能查询额度——这是平台侧限制(CodexBar / cc-switch 等第三方同此结论)。

查询走 `platform.xiaomimimo.com/api/v1` 的 `tokenPlan/usage`、`tokenPlan/detail`、`balance` 三端点:用量为主窗口来源,周期截止与余额为尽力而为的增强行,失败不阻塞主窗口。缺凭据 / Cookie 缺字段 / 登录态过期各有双语专属提示;plan/API 双轨分类新增 mimo 别名归并(`xiaomi-token-plan-*` 等 provider id 计入 MiMo 订阅轨)。

### Upgrade / 升级

Update the plugin and open **Settings → Cost → Quotas → Xiaomi MiMo Token Plan**, enable it and paste the console cookie, then click **Refresh**. / 更新插件后打开**设置 → 费用 → 额度 → 小米 MiMo Token Plan**,启用并粘贴控制台 Cookie,点击**刷新**即可。
