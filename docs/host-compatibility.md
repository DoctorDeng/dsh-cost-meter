每个宿主使用独立安装目录和 `DSH_HOME`；测试终端清除了继承的 API 凭据。探针核对实际加载的插件版本为 1.7.15，两个宿主 peer 模块均解析到宿主的同一文件。停止服务并卸载后，配置与插件包已移除，账本仍在。未发起模型请求，未运行 Desktop 整个桌面外壳。

本版另外通过 Asia/Shanghai 与 UTC 全量回归：同名模型的千问订阅/按量渠道隔离、真实服务 Credits 过滤、美元/人民币默认峰谷档位、会话投影、历史日志完整性、分段日志合并、升级中断恢复、配置清空和幂等检查。
